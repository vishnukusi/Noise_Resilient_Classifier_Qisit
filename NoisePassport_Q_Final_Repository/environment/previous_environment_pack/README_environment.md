# NoisePassport-Q environment and processor configuration pack

This folder contains:
- `requirements.txt` — proposed Python dependencies.
- `environment.txt` — environment record template.
- `environment-notes.md` — setup instructions and fields to fill in.
- `processor_definitions.json` — machine-readable simulator profiles.
- `processor_definitions.md` — explanation and data-recording guidance.

## Important
No files in this pack prove that the dependencies were installed or the experiment was run. The noise values are illustrative synthetic stress settings, not hardware calibration. Confirm the official Q3 instructions before use, then validate the environment with a clean install and smoke test.
